Generator Jadwal Piket

Alat canggih untuk membuat jadwal piket siswa dengan pembagian tugas yang merata dan adil.

Input Data Siswa

Masukkan nama siswa per baris. Format: Nama Kelas atau Nama[TAB]Kelas[TAB]L/P.

Data tersimpan otomatis di browser Anda.

Input Data Tugas

Format: Lokasi - Deskripsi Tugas [prioritas]. Jika tidak ada [L] atau [P], tugas bisa diisi siapa saja.

Data tersimpan otomatis di browser Anda.
