2. Penjelasan Berpikir Komputasional
2. Pengenalan Pola (Membaca Keteraturan)
Otak mengelompokkan baris secara instan menjadi 2 tipe logika:
• Pola Simetri: Kiri-Kanan sama (✊-✊ / ✋-✋).
• Pola Asimetri: Kiri-Kanan silang (✊-✋ / ✋-✊).
3. Abstraksi (Menyaring Informasi)
Pemain mengabaikan dekorasi visual (warna grid, nomor urut, tombol acak).
Hanya fokus pada data penting: Bentuk Simbol dan Posisi Kolom.
4. Algoritma (Eksekusi Terstruktur)
Otak menjalankan langkah sekuensial yang kaku:
Mulai → Baris 1 → Baris 2 → Baris 3 → Baris 4 → Selesai.
Urutan tidak boleh melompat agar tidak terjadi error gerakan.
Kesimpulan: Permainan ini membuktikan bahwa Berpikir Komputasional adalah metode berpikir kognitif manusia dalam memproses informasi, bukan sekadar tentang menulis kode komputer.
